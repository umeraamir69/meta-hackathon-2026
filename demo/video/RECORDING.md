# How to finish the submit video (with this voiceover)

AI cannot produce a valid **product demo** for judges (they need your real site/UI).  
Use this voice track while you screen-record.

## Files

| File | What |
|------|------|
| [`voiceover.m4a`](./voiceover.m4a) | Spoken script (~**94s**) — Reed US voice |
| [`voiceover-script.txt`](./voiceover-script.txt) | Exact words |
| Full click list | [`../../VIDEO_TRANSCRIPT.md`](../../VIDEO_TRANSCRIPT.md) |

You have ~**2:30** left after VO for waiting on scans / clicks (total ≤ 3:00).

## Record (macOS — ~10 minutes)

1. Open tabs from `VIDEO_TRANSCRIPT.md` (Fail prefill, AI Pass, GitHub PR, Terminal demo).
2. Reload extension **0.5.2**.
3. Play voiceover once to rehearse timing (`afplay demo/video/voiceover.m4a`).
4. **QuickTime Player** → File → New Screen Recording → record main display.
5. Start **QuickTime**, then start **voiceover** (`afplay` or Music), then click through:
   - Site Fail scan → report → Muse chat  
   - AI Pass flash  
   - Extension on PR  
   - Terminal hook FAIL  
   - Home page close  
6. Stop at ≤ **3:00**. Trim in QuickTime (Edit → Trim).
7. Export → upload YouTube **Unlisted** or Loom (viewable logged-out).
8. Paste URL into CV form + `SUBMISSION.md`.

### Optional: system audio in the recording

QuickTime alone often **won’t** capture `afplay`. Easiest options:

- Speak yourself live while recording (best for authenticity), using the transcript, **or**
- Use **Loom** / **OBS** with desktop audio, play `voiceover.m4a` while recording, **or**
- Record screen silent in QuickTime, then in iMovie: add `voiceover.m4a` under the clip and export.
