\begin{abstract}
Deleting a credential from the latest file does not remove it from git history.
Diff-only and working-tree scanners can report a clean pull request while the leak remains recoverable from prior commits.
We present \emph{PR Diff Sentinel}, a deterministic merge gate over the working tree, the pull-request diff, and git history.
Pass/Fail is decided only by rules.
Meta Muse Spark labels masked findings and Muse Wonder writes rotation guidance and report chat; neither model can clear a Fail.
We report a mini-evaluation on synthetic history-leak fixtures comparing history-aware Sentinel against tree-only baselines (Sentinel with history disabled; Gitleaks \texttt{--no-git}).
\end{abstract}
